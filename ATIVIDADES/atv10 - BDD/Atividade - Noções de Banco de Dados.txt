15.Explique, com suas palavras:
a. Por que uma boa modelagem de dados facilita a implementação e manutenção do banco de dados.

Uma boa modelagem atua como o projeto arquitetônico do banco de dados, o que é crucial.

Implementação: Facilita ao fornecer um guia claro para desenvolvedores, definindo entidades e regras (chaves primárias/estrangeiras) antes da codificação.

Manutenção: Garante que os dados sejam consistentes e menos redundantes (via Normalização), simplificando futuras atualizações.

Extensibilidade: Permite que novos recursos sejam adicionados facilmente, pois a estrutura lógica do sistema é clara e documentada.

Performance: Otimiza a estrutura para consultas mais eficientes e rápidas, melhorando o desempenho a longo prazo.

Custo: Resolver problemas no modelo conceitual é mais rápido e barato do que corrigir erros no código implementado.

b. Como um SGBD ajuda a evitar erros humanos e problemas de redundância.
Um Sistema de Gerenciamento de Banco de Dados (SGBD) ajuda a evitar erros humanos e problemas de redundância ao impor regras de forma centralizada, tirando a responsabilidade de manter a coerência das aplicações ou dos usuários.
